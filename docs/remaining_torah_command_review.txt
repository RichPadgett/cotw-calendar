Remaining Torah Command Review Checklist
========================================

Purpose
-------
This is a review-only checklist for Torah command candidates that are not yet
fully represented, or may only be represented broadly, in the current Prolog
catalog.

Source rule for future cataloging:
- Use written Torah wording first.
- Do not turn rabbinic fences, later summaries, or denominational applications
  into commands.
- Use traditional 613 lists only as a coverage aid, not as final wording.
- Verify each command against the Torah passage before adding it to Prolog.

Current Prolog catalog count after promoting this checklist: 464 commands.
