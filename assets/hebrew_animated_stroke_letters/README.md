# Animated Hebrew Stroke Letters

This set contains 27 standalone SVG files: the 22 standard Hebrew letters and 5 final forms.

Features:
- Hand-drawn monoline paths rather than font outlines
- Sequential stroke animation
- Numbered stroke starting points
- Pale guide paths and baseline
- Standalone SVGs plus an `index.html` gallery

Open `index.html` in a browser. Each SVG can also be embedded independently.

Note: Stroke order and letter construction vary by handwriting, educational tradition, and calligraphic style. This set is a consistent modern block-hand teaching approximation.
